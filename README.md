# DSA Journey: From Beginner to Better Problem Solver

I am learning Data Structures and Algorithms from the basics and solving problems regularly using JavaScript. The goal of this repository is to build a strong problem-solving foundation, stay consistent, and keep a public record of my progress.

## Goals

- Learn Data Structures and Algorithms from scratch
- Solve at least one Easy or Medium problem every day
- Understand multiple approaches to the same problem
- Analyze time and space complexity for every solution
- Prepare for coding interviews and technical assessments

## Daily Practice Routine

1. Read and understand the problem statement
2. Try to solve it independently before looking at any hints
3. Write a clean, readable JavaScript solution
4. Test the solution against edge cases
5. Note the time and space complexity in a comment at the top of the file
6. Commit and push to GitHub

Each solution file follows this header format:

```js
// Problem: Find Second Largest Number in an Array
// Difficulty: Easy
// Topic: Arrays
// Approach: Single pass tracking largest and second largest
// Time Complexity: O(n)
// Space Complexity: O(1)
```
